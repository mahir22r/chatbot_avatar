## 📱 Quick Commands

### Install
```bash
pip install -r requirements.txt
```

### Configure
```bash
# Create .env file with:
LLM_ENDPOINT=your_endpoint
LLM_MODEL_NAME=your_model
API_KEY=your_key
```

### Run
```bash
python web_app.py
```

### Access
```
http://localhost:5000
```
