## 🔊 Voice Features

### Voice Input 🎤

```
PROCESS:
1. Click microphone button 🎤
2. Button turns red and pulses
3. Microphone indicator shows: "Listening..."
4. Speak your message clearly
5. Message auto-transcribed to text
6. Auto-sends when you finish speaking
7. Button returns to normal 🎤

EXAMPLE:
Click 🎤 → "Listening..."
Speak: "What's the weather like?"
[Transcribed to text box]
[Auto-sent as message]
Mike responds immediately!
```

### Text-to-Speech 🔊

```
PROCESS:
1. Mike's response is generated
2. Text appears in chat box
3. Mike begins speaking with natural voice
4. Mouth animates with speech
5. Voice continues until message complete
6. Avatar returns to idle state

CONFIGURATION:
- Rate: 0.9 (slightly slow for clarity)
- Pitch: 1.1 (slightly higher, feminine)
- Volume: 0.9 (comfortable level)
- Voice: Female (preferred if available)
```

## 🐛 Troubleshooting Visual Guide

### Issue: Avatar Not Visible

```
CHECK LIST:
□ Canvas area showing (light background)?
└─ If no: Browser not rendering canvas

SOLUTIONS:
1. Open DevTools (F12)
   └─ Check console for errors
2. Try different browser
   └─ Chrome/Firefox recommended
3. Check GPU support
   └─ WebGL must be enabled
4. Disable extensions
   └─ They might block WebGL
```

### Issue: Avatar Not Animating

```
CHECK LIST:
□ Avatar visible but static?
□ Can rotate camera?

SOLUTIONS:
1. Check FPS in console
   └─ Should show 55+ fps
2. Close background tabs
   └─ Reduces CPU load
3. Update graphics drivers
   └─ Improves GPU performance
4. Try demo website
   └─ Test if WebGL works
```

### Issue: Voice Not Working

```
CHECK LIST:
□ Microphone connected?
□ Browser has permission?
□ Volume turned up?

SOLUTIONS:
1. Check microphone permissions
   └─ Allow access in browser settings
2. Test system audio first
   └─ Use system app to test
3. Try different browser
   └─ Test voice in another app
4. Restart browser
   └─ Sometimes permissions reset
```

### Issue: Responses Delayed

```
CHECK LIST:
□ Internet connection good?
□ Backend running?
□ LLM API responding?

SOLUTIONS:
1. Check backend logs
   └─ Look for errors in terminal
2. Test connection
   └─ Status should show "Connected"
3. Check API endpoint
   └─ Verify .env file is correct
4. Wait a moment
   └─ LLM might need time (1-5 seconds)
```
